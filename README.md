# Roadmap Nightz · Qiu Agency

Portal del proyecto **Nightz by Zona Viva**, desarrollado por Qiu Agency (Qiu Capital Group, C.A.).

- `index.html` — roadmap del proyecto (fases, entregables, pendientes, hitos de pago y documentos)
- `nightz-icono.png` — ícono de la app (boceto A)
- `nightz-propuesta-logo.png` — propuesta de logo (bocetos A y B)
- `nightz-foto-grupo.png` — foto del grupo de WhatsApp

Para actualizar el avance, editar el bloque `DATOS DEL PROYECTO` dentro de `index.html`.

Los documentos con datos comerciales y de pago están en el repositorio privado `nightz-documentos` y en la carpeta de Google Drive del proyecto.
